# Fraud Network Graph Intelligence - Next.js Frontend Placeholder

This folder contains a placeholder dashboard application built with Next.js, React, and TypeScript. It is designed to visualize the fraud connection clusters generated by the backend's graph intelligence analyzer.

## Prerequisites

- [Node.js](https://nodejs.org/) (v18.0.0 or higher)
- NPM, Yarn, or PNPM

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Open the browser**:
   Navigate to [http://localhost:3000](http://localhost:3000) to see the dashboard.

## Folder Structure

- `src/pages/index.tsx`: The primary dashboard placeholder configured with modern dark-mode aesthetics.
- `tsconfig.json`: TypeScript configurations.
